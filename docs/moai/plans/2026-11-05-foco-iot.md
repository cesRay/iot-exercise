# Plan de implementación: foco RGB controlado por Internet

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or build to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** construir la demo de IoT descrita en `ARCHITECTURE.md`: una página web en la laptop cambia el encendido, el color y el brillo de un foco WiZ a través de AWS IoT Core y una Raspberry Pi.

**Arquitectura:** Terraform crea en AWS el thing `foco-aula`, su certificado, las políticas y un grupo de identidades de Cognito con acceso de invitado. También genera los archivos de configuración del puente y de la página. El puente (Python, en la Pi) escucha los cambios de la sombra (Device Shadow), los envía al foco por UDP y reporta el estado confirmado. La página (HTML y JavaScript sin framework) se conecta a AWS IoT Core por MQTT sobre WebSockets, con una URL firmada con SigV4.

**Tecnologías:** Terraform 1.6+ (proveedor `hashicorp/aws` 6.x), AWS IoT Core, Amazon Cognito, Python 3.11+ (`awsiotsdk`, `pywizlight`, `pytest`), JavaScript en el navegador (`mqtt.js` 5.16.1 desde unpkg, Web Crypto), Node 20+ solo para las pruebas (`node --test`), systemd en Raspberry Pi OS Lite.

**Estado del código:** todo el código de este plan ya se ejecutó en un entorno de prueba el 2026-11-05: 27 pruebas de Python, 9 pruebas de JavaScript y `terraform validate` pasan. La firma SigV4 coincide con el vector de prueba de la documentación de AWS.

```markdown
## Manejo de errores

| Situación | Qué hace el sistema | Qué ve la página |
|---|---|---|
| La Pi se desconecta | AWS IoT Core publica `offline` en `aula/foco/disponible` (Last Will) | Gateway: "fuera de línea" |
| El foco no responde | El puente lo busca de nuevo en la red y reintenta una vez. Si falla otra vez, no reporta nada. | A los 5 segundos: "El foco no confirmó el cambio" |
| La IP del foco cambia | Si `config.toml` no tiene IP fija, el puente busca el foco con un mensaje UDP de difusión (broadcast) | Nada: el cambio es transparente |
| Un valor inválido en `desired` | El puente descarta ese campo, aplica los válidos y borra el campo inválido del estado deseado | El control vuelve al valor confirmado |
| La página pierde la conexión | Pide credenciales nuevas a Cognito y reconecta cada 3 segundos | Conexión: "desconectado, reintentando…" |
| Se pidió un cambio con la Pi apagada | Al reconectar, el puente reporta el estado del foco. AWS IoT Core envía el delta y el puente lo aplica. | El cambio se aplica solo |
| AWS IoT Core rechaza una actualización | Publica el motivo en `shadow/update/rejected` | El mensaje con el motivo |

El brillo va de 10 a 100 porque los focos WiZ no bajan del 10 %. Con un mínimo de 0, el foco reportaría 10 y la página quedaría esperando una confirmación que nunca llega.
```

### Tarea 4: thing, certificado y política del puente

**Archivos:**
- Crear: `infra/iot.tf`

- [ ] **Paso 1: crear `infra/iot.tf`**

```hcl
data "aws_caller_identity" "actual" {}

data "aws_iot_endpoint" "datos" {
  endpoint_type = "iot:Data-ATS"
}

locals {
  arn_iot = "arn:aws:iot:${var.region}:${data.aws_caller_identity.actual.account_id}"
  sombra  = "$aws/things/${var.thing_name}/shadow"
}

resource "aws_iot_thing" "foco" {
  name = var.thing_name
}

# Certificado X.509 del puente. AWS genera la llave privada y Terraform la guarda en el estado local.
resource "aws_iot_certificate" "gateway" {
  active = true
}

resource "aws_iot_thing_principal_attachment" "gateway" {
  thing     = aws_iot_thing.foco.name
  principal = aws_iot_certificate.gateway.arn
}

# El puente solo puede conectarse como el thing y usar su sombra y el tema de disponibilidad.
resource "aws_iot_policy" "gateway" {
  name = "${var.thing_name}-gateway"
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = "iot:Connect"
        Resource = "${local.arn_iot}:client/${var.thing_name}"
      },
      {
        Effect = "Allow"
        Action = ["iot:Publish", "iot:Receive"]
        Resource = [
          "${local.arn_iot}:topic/${local.sombra}/*",
          "${local.arn_iot}:topic/${var.topico_disponible}",
        ]
      },
      {
        Effect   = "Allow"
        Action   = "iot:RetainPublish"
        Resource = "${local.arn_iot}:topic/${var.topico_disponible}"
      },
      {
        Effect   = "Allow"
        Action   = "iot:Subscribe"
        Resource = "${local.arn_iot}:topicfilter/${local.sombra}/*"
      },
    ]
  })
}

resource "aws_iot_policy_attachment" "gateway" {
  policy = aws_iot_policy.gateway.name
  target = aws_iot_certificate.gateway.arn
}

# Archivos que el puente necesita. Están en .gitignore: nunca se suben al repositorio.
data "http" "amazon_root_ca" {
  url = "https://www.amazontrust.com/repository/AmazonRootCA1.pem"
}

resource "local_file" "gateway_cert" {
  filename        = "${path.module}/../bridge/certs/certificate.pem.crt"
  content         = aws_iot_certificate.gateway.certificate_pem
  file_permission = "0644"
}

resource "local_sensitive_file" "gateway_key" {
  filename        = "${path.module}/../bridge/certs/private.pem.key"
  content         = aws_iot_certificate.gateway.private_key
  file_permission = "0600"
}

resource "local_file" "amazon_root_ca" {
  filename        = "${path.module}/../bridge/certs/AmazonRootCA1.pem"
  content         = data.http.amazon_root_ca.response_body
  file_permission = "0644"
}

resource "local_file" "bridge_config" {
  filename        = "${path.module}/../bridge/config.toml"
  file_permission = "0644"
  content         = <<-EOT
    # Generado por Terraform (infra/iot.tf). No lo edites a mano: cambia las variables y ejecuta terraform apply.
    endpoint = "${data.aws_iot_endpoint.datos.endpoint_address}"
    thing_name = "${var.thing_name}"
    topico_disponible = "${var.topico_disponible}"

    [certificados]
    cert = "certs/certificate.pem.crt"
    key = "certs/private.pem.key"
    ca = "certs/AmazonRootCA1.pem"

    [foco]
    # Vacío: el puente busca el foco en la red. Escribe la IP si la búsqueda falla.
    ip = ""
    broadcast = "172.20.10.15"
  EOT
}
```

Detalles importantes de la política:
- `iot:RetainPublish` es obligatorio para publicar con *retain*, incluido el mensaje de Last Will.
- Los temas que empiezan con `$aws` usan `$` literal. En HCL solo `${` inicia una interpolación.

```hcl
# Grupo de identidades con acceso de invitado: la página obtiene credenciales temporales sin iniciar sesión.
resource "aws_cognito_identity_pool" "web" {
  identity_pool_name               = "foco_aula_web"
  allow_unauthenticated_identities = true
  allow_classic_flow               = false
}

resource "aws_iam_role" "web_invitado" {
  name = "${var.thing_name}-web-invitado"
  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect    = "Allow"
        Principal = { Federated = "cognito-identity.amazonaws.com" }
        Action    = "sts:AssumeRoleWithWebIdentity"
        Condition = {
          StringEquals = {
            "cognito-identity.amazonaws.com:aud" = aws_cognito_identity_pool.web.id
          }
          "ForAnyValue:StringLike" = {
            "cognito-identity.amazonaws.com:amr" = "unauthenticated"
          }
        }
      },
    ]
  })
}

locals {
  topicos_web = [
    "${local.sombra}/update/documents",
    "${local.sombra}/update/rejected",
    "${local.sombra}/get/accepted",
    "${local.sombra}/get/rejected",
    var.topico_disponible,
  ]
}

# El invitado solo puede pedir cambios a la sombra del foco y escuchar sus respuestas.
resource "aws_iam_role_policy" "web_invitado_iot" {
  name = "control-foco"
  role = aws_iam_role.web_invitado.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = "iot:Connect"
        Resource = "${local.arn_iot}:client/web-*"
      },
      {
        Effect = "Allow"
        Action = "iot:Publish"
        Resource = [
          "${local.arn_iot}:topic/${local.sombra}/update",
          "${local.arn_iot}:topic/${local.sombra}/get",
        ]
      },
      {
        Effect   = "Allow"
        Action   = "iot:Subscribe"
        Resource = [for topico in local.topicos_web : "${local.arn_iot}:topicfilter/${topico}"]
      },
      {
        Effect   = "Allow"
        Action   = "iot:Receive"
        Resource = [for topico in local.topicos_web : "${local.arn_iot}:topic/${topico}"]
      },
    ]
  })
}

resource "aws_cognito_identity_pool_roles_attachment" "web" {
  identity_pool_id = aws_cognito_identity_pool.web.id
  roles = {
    unauthenticated = aws_iam_role.web_invitado.arn
  }
}

resource "local_file" "web_config" {
  filename        = "${path.module}/../web/config.js"
  file_permission = "0644"
  content         = <<-EOT
    // Generado por Terraform (infra/cognito.tf). No lo edites a mano.
    export const CONFIG = {
      region: "${var.region}",
      endpoint: "${data.aws_iot_endpoint.datos.endpoint_address}",
      identityPoolId: "${aws_cognito_identity_pool.web.id}",
      thingName: "${var.thing_name}",
      topicoDisponible: "${var.topico_disponible}",
    };
  EOT
}
```

Para identidades de invitado, AWS IoT Core solo evalúa la política del rol de IAM. No hace falta adjuntar una política de IoT a la identidad.

```python
"""Estado del foco y validación de los cambios que llegan desde la sombra."""

import re
from dataclasses import dataclass, replace

BRILLO_MINIMO = 10
BRILLO_MAXIMO = 100
_COLOR_HEX = re.compile(r"#[0-9a-fA-F]{6}")


class CambioInvalido(ValueError):
    """Un campo del estado deseado tiene un valor que el foco no puede aplicar."""


@dataclass(frozen=True)
class EstadoFoco:
    encendido: bool
    color: str  # "#rrggbb" en minúsculas
    brillo: int  # de BRILLO_MINIMO a BRILLO_MAXIMO

    def a_dict(self) -> dict:
        return {"encendido": self.encendido, "color": self.color, "brillo": self.brillo}


ESTADO_INICIAL = EstadoFoco(encendido=False, color="#ffffff", brillo=BRILLO_MAXIMO)


def _validar_encendido(valor: object) -> bool:
    if not isinstance(valor, bool):
        raise CambioInvalido(f"encendido debe ser true o false, no {valor!r}")
    return valor


def _validar_color(valor: object) -> str:
    if not isinstance(valor, str) or not _COLOR_HEX.fullmatch(valor):
        raise CambioInvalido(f"color debe tener el formato #rrggbb, no {valor!r}")
    return valor.lower()


def _validar_brillo(valor: object) -> int:
    if isinstance(valor, bool) or not isinstance(valor, int):
        raise CambioInvalido(f"brillo debe ser un entero, no {valor!r}")
    if not BRILLO_MINIMO <= valor <= BRILLO_MAXIMO:
        raise CambioInvalido(f"brillo debe estar entre {BRILLO_MINIMO} y {BRILLO_MAXIMO}, no {valor}")
    return valor


_VALIDADORES = {
    "encendido": _validar_encendido,
    "color": _validar_color,
    "brillo": _validar_brillo,
}


def aplicar_cambios(actual: EstadoFoco, cambios: dict) -> tuple[EstadoFoco, dict[str, str]]:
    """Aplica los campos válidos. Devuelve el estado nuevo y los campos descartados con su motivo."""
    validos: dict[str, object] = {}
    invalidos: dict[str, str] = {}
    for campo, valor in cambios.items():
        validar = _VALIDADORES.get(campo)
        if validar is None:
            invalidos[campo] = "campo desconocido"
            continue
        try:
            validos[campo] = validar(valor)
        except CambioInvalido as error:
            invalidos[campo] = str(error)
    return replace(actual, **validos), invalidos
```

```python
"""Temas MQTT y documentos JSON de la sombra (Device Shadow) de AWS IoT Core."""

import json
from collections.abc import Iterable
from dataclasses import dataclass

from foco_bridge.estado import EstadoFoco


@dataclass(frozen=True)
class Topicos:
    update: str
    delta: str
    disponible: str

    @classmethod
    def para(cls, thing_name: str, disponible: str) -> "Topicos":
        base = f"$aws/things/{thing_name}/shadow"
        return cls(update=f"{base}/update", delta=f"{base}/update/delta", disponible=disponible)


def payload_reportado(estado: EstadoFoco, descartar: Iterable[str] = ()) -> bytes:
    """Documento que reporta el estado real. Los campos de `descartar` se borran del estado deseado."""
    documento: dict = {"state": {"reported": estado.a_dict()}}
    campos = list(descartar)
    if campos:
        documento["state"]["desired"] = {campo: None for campo in campos}
    return json.dumps(documento).encode()


def leer_delta(payload: bytes) -> dict:
    """Extrae los cambios pendientes de un mensaje del tema delta. Devuelve {} si el mensaje no sirve."""
    try:
        documento = json.loads(payload)
    except (json.JSONDecodeError, UnicodeDecodeError):
        return {}
    estado = documento.get("state") if isinstance(documento, dict) else None
    return estado if isinstance(estado, dict) else {}
```

```python
import tomllib
from dataclasses import dataclass
from pathlib import Path

    key: Path

        cert=base / certificados["cert"],
        key=base / certificados["key"],
        ca=base / certificados["ca"],
        foco_ip=foco.get("ip") or None,
        broadcast=foco.get("broadcast", BROADCAST_HOTSPOT),
    )
```

```python
"""Acceso al foco: el foco WiZ real (UDP en la red local) y un foco simulado para desarrollar sin hardware."""

import asyncio
import logging
from typing import Protocol

from pywizlight import PilotBuilder, wizlight
from pywizlight.discovery import discover_lights

from foco_bridge.color import brillo_a_wiz, hex_a_rgb, rgb_a_hex, wiz_a_brillo
from foco_bridge.estado import ESTADO_INICIAL, EstadoFoco

log = logging.getLogger(__name__)


class FocoNoEncontrado(RuntimeError):
    """No hay ningún foco WiZ que responda en la red."""


class Foco(Protocol):
    async def leer(self) -> EstadoFoco: ...

    async def aplicar(self, estado: EstadoFoco) -> None: ...


class FocoSimulado:
    """Guarda el estado en memoria. Sirve para probar el puente sin el foco."""

    def __init__(self, inicial: EstadoFoco = ESTADO_INICIAL) -> None:
        self._estado = inicial

    async def leer(self) -> EstadoFoco:
        return self._estado

    async def aplicar(self, estado: EstadoFoco) -> None:
        log.info("Foco simulado: %s", estado)
        self._estado = estado


async def descubrir(broadcast: str) -> str:
    """Busca focos WiZ con un mensaje de difusión (broadcast) y devuelve la IP del primero."""
    focos = await discover_lights(broadcast_space=broadcast)
    if not focos:
        raise FocoNoEncontrado(f"No respondió ningún foco WiZ en {broadcast}")
    log.info("Foco WiZ encontrado en %s", focos[0].ip)
    return focos[0].ip


class FocoWiz:
    """Foco WiZ real. Si no hay IP fija, lo busca en la red y lo vuelve a buscar cuando deja de responder."""

    def __init__(self, ip: str | None, broadcast: str, tiempo_maximo: float = 5.0) -> None:
        self._ip = ip
        self._broadcast = broadcast
        self._tiempo_maximo = tiempo_maximo
        self._luz_actual: wizlight | None = None

    async def leer(self) -> EstadoFoco:
        luz = await self._luz()
        estado = await asyncio.wait_for(luz.updateState(), self._tiempo_maximo)
        rgb = estado.get_rgb()
        brillo = estado.get_brightness()
        return EstadoFoco(
            encendido=bool(estado.get_state()),
            color=rgb_a_hex(rgb) if None not in rgb else ESTADO_INICIAL.color,
            brillo=wiz_a_brillo(brillo) if brillo is not None else ESTADO_INICIAL.brillo,
        )

    async def aplicar(self, estado: EstadoFoco) -> None:
        try:
            await self._enviar(estado)
        except Exception:
            log.warning("El foco no respondió. Se buscará de nuevo y se reintentará una vez.")
            await self._olvidar()
            await self._enviar(estado)

    async def _enviar(self, estado: EstadoFoco) -> None:
        luz = await self._luz()
        if estado.encendido:
            orden = luz.turn_on(PilotBuilder(rgb=hex_a_rgb(estado.color), brightness=brillo_a_wiz(estado.brillo)))
        else:
            orden = luz.turn_off()
        await asyncio.wait_for(orden, self._tiempo_maximo)

    async def _luz(self) -> wizlight:
        if self._luz_actual is None:
            ip = self._ip or await descubrir(self._broadcast)
            self._luz_actual = wizlight(ip)
        return self._luz_actual

    async def _olvidar(self) -> None:
        if self._luz_actual is not None:
            await self._luz_actual.async_close()
            self._luz_actual = None
```

Notas sobre `pywizlight` 0.6.7:
- `get_rgb()` devuelve `(None, None, None)` cuando el foco está en modo blanco. Por eso `leer()` usa el color de `ESTADO_INICIAL` en ese caso.
- El brillo de `PilotBuilder` va de 0 a 255. El foco lo guarda como porcentaje.

```python
import logging

from foco_bridge.estado import EstadoFoco, aplicar_cambios
from foco_bridge.foco import Foco

Publicar = Callable[[str, bytes], None]

        self._foco = foco
        self._publicar = publicar
        self._topicos = topicos
        self._estado: EstadoFoco | None = None
        self._candado = asyncio.Lock()

    async def sincronizar(self) -> None:
        """Lee el foco y reporta su estado. Si difiere del deseado, AWS IoT Core envía un delta."""
        async with self._candado:
            self._estado = await self._foco.leer()
            self._publicar(self._topicos.update, payload_reportado(self._estado))

    async def procesar_delta(self, payload: bytes) -> None:
        cambios = leer_delta(payload)
        if not cambios:
            return
        async with self._candado:
            actual = self._estado or await self._foco.leer()
            nuevo, invalidos = aplicar_cambios(actual, cambios)
            for campo, motivo in invalidos.items():
                log.warning("Cambio descartado en '%s': %s", campo, motivo)
            if nuevo != actual:
                try:
                    await self._foco.aplicar(nuevo)
                except Exception:
                    log.exception("El foco no aplicó el cambio. El estado reportado no cambia.")
                    if not invalidos:
                        return
                    nuevo = actual
            self._estado = nuevo
            self._publicar(self._topicos.update, payload_reportado(nuevo, descartar=invalidos))
```

```python
import asyncio

from awsiot import mqtt_connection_builder

async def ejecutar(config: Config, simular: bool) -> None:
    loop = asyncio.get_running_loop()
    topicos = Topicos.para(config.thing_name, config.topico_disponible)
    foco = FocoSimulado() if simular else FocoWiz(config.foco_ip, config.broadcast)

    def publicar(topico: str, payload: bytes, retener: bool = False) -> None:
        conexion.publish(topic=topico, payload=payload, qos=mqtt.QoS.AT_LEAST_ONCE, retain=retener)

    puente = Puente(foco, publicar, topicos)

    async def al_reconectar(sesion_presente: bool) -> None:
        if not sesion_presente:
            await asyncio.wrap_future(conexion.resubscribe_existing_topics()[0])
        publicar(topicos.disponible, b"online", retener=True)
        await puente.sincronizar()

    # Las funciones de awscrt corren en otro hilo: los cambios se pasan al bucle de asyncio.
    def al_recibir_delta(topic: str, payload: bytes, **kwargs) -> None:
        asyncio.run_coroutine_threadsafe(puente.procesar_delta(payload), loop)

    def al_reanudar(connection, return_code, session_present: bool, **kwargs) -> None:
        log.info("Conexión con AWS IoT Core recuperada")
        asyncio.run_coroutine_threadsafe(al_reconectar(session_present), loop)

    def al_interrumpir(connection, error, **kwargs) -> None:
        log.warning("Conexión con AWS IoT Core interrumpida: %s", error)

    conexion = mqtt_connection_builder.mtls_from_path(
        endpoint=config.endpoint,
        cert_filepath=str(config.cert),
        pri_key_filepath=str(config.key),
        ca_filepath=str(config.ca),
        client_id=config.thing_name,
        clean_session=False,
        keep_alive_secs=30,
        will=mqtt.Will(topic=topicos.disponible, qos=mqtt.QoS.AT_LEAST_ONCE, payload=b"offline", retain=True),
        on_connection_interrupted=al_interrumpir,
        on_connection_resumed=al_reanudar,
    )

    log.info("Conectando a %s como %s", config.endpoint, config.thing_name)
    await asyncio.wrap_future(conexion.connect())
    suscripcion, _ = conexion.subscribe(
        topic=topicos.delta, qos=mqtt.QoS.AT_LEAST_ONCE, callback=al_recibir_delta
    )
    await asyncio.wrap_future(suscripcion)
    publicar(topicos.disponible, b"online", retener=True)
    await puente.sincronizar()
    log.info("Puente listo%s", " (foco simulado)" if simular else "")

    parar = asyncio.Event()
    for senal in (signal.SIGINT, signal.SIGTERM):
        loop.add_signal_handler(senal, parar.set)
    await parar.wait()

    log.info("Cerrando el puente")
    despedida, _ = conexion.publish(
        topic=topicos.disponible, payload=b"offline", qos=mqtt.QoS.AT_LEAST_ONCE, retain=True
    )
    await asyncio.wrap_future(despedida)
    await asyncio.wrap_future(conexion.disconnect())


def main() -> None:
    parser = argparse.ArgumentParser(description="Puente entre AWS IoT Core y un foco WiZ")
    parser.add_argument("--config", type=Path, default=Path("config.toml"))
    parser.add_argument("--simular", action="store_true", help="usar un foco simulado en memoria")
    args = parser.parse_args()
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s: %(message)s")
    asyncio.run(ejecutar(cargar(args.config), args.simular))

    main()
```

Notas sobre `awscrt`:
- Las funciones de respuesta (*callbacks*) de `subscribe` y `on_connection_resumed` corren en un hilo de awscrt. Por eso pasan el trabajo al bucle de asyncio con `run_coroutine_threadsafe`.
- `subscribe` puede llamar a la función solo con `topic` y `payload`. Por eso la firma es `(topic, payload, **kwargs)`.
- `clean_session=False` mantiene las suscripciones en AWS IoT Core si la conexión se corta. Si la sesión no se conservó, `al_reconectar` vuelve a suscribirse.

```javascript
// Temas MQTT y documentos de la sombra del foco, sin dependencias del navegador.

export const BRILLO_MINIMO = 10;
export const BRILLO_MAXIMO = 100;
const COLOR_HEX = /^#[0-9a-f]{6}$/i;

export function topicos(thingName, topicoDisponible) {
  const base = `$aws/things/${thingName}/shadow`;
  return {
    update: `${base}/update`,
    documentos: `${base}/update/documents`,
    rechazado: `${base}/update/rejected`,
    get: `${base}/get`,
    getAceptado: `${base}/get/accepted`,
    disponible: topicoDisponible,
  };
}

export function payloadDeseado(cambios) {
  const { encendido, color, brillo } = cambios;
  if (encendido !== undefined && typeof encendido !== "boolean") {
    throw new TypeError(`encendido debe ser true o false, no ${encendido}`);
  }
  if (color !== undefined && !COLOR_HEX.test(color)) {
    throw new TypeError(`color debe tener el formato #rrggbb, no ${color}`);
  }
  if (brillo !== undefined && !(Number.isInteger(brillo) && brillo >= BRILLO_MINIMO && brillo <= BRILLO_MAXIMO)) {
    throw new TypeError(`brillo debe ser un entero entre ${BRILLO_MINIMO} y ${BRILLO_MAXIMO}, no ${brillo}`);
  }
  const deseado = Object.fromEntries(
    Object.entries({ encendido, color: color?.toLowerCase(), brillo }).filter(([, valor]) => valor !== undefined),
  );
  return JSON.stringify({ state: { desired: deseado } });
}

// Resume un estado de la sombra: lo que el foco confirmó y si falta aplicar algo de lo pedido.
function resumir(estado = {}) {
  const reportado = estado.reported ?? null;
  const deseado = estado.desired ?? {};
  const pendiente = Object.entries(deseado).some(([campo, valor]) => reportado?.[campo] !== valor);
  return { reportado, pendiente };
}

// Mensaje del tema .../shadow/update/documents
export function leerDocumentos(texto) {
  return resumir(JSON.parse(texto).current?.state);
}

// Mensaje del tema .../shadow/get/accepted
export function leerGetAceptado(texto) {
  return resumir(JSON.parse(texto).state);
}
```

```javascript
const enc = new TextEncoder();
function aHex(buffer) { return [...new Uint8Array(buffer)].map((b) => b.toString(16).padStart(2, "0")).join(""); }
async function sha256Hex(texto) { return aHex(await crypto.subtle.digest("SHA-256", enc.encode(texto))); }
async function hmac(clave, texto) {
  const material = typeof clave === "string" ? enc.encode(clave) : clave;
  const k = await crypto.subtle.importKey("raw", material, { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);
  return crypto.subtle.sign("HMAC", k, enc.encode(texto));
}
export async function claveDeFirma(secreto, fecha, region, servicio) {
  let k = await hmac(`AWS4${secreto}`, fecha); k = await hmac(k, region); k = await hmac(k, servicio); return hmac(k, "aws4_request");
}
export function fechaAmz(fecha) { const amzDate = fecha.toISOString().replace(/[:-]|\.\d{3}/g, ""); return { amzDate, dateStamp: amzDate.slice(0, 8) }; }
export async function urlFirmada({ host, region, credenciales, ahora = new Date() }) {
  const servicio = "iotdevicegateway";
  const { amzDate, dateStamp } = fechaAmz(ahora);
  const alcance = `${dateStamp}/${region}/${servicio}/aws4_request`;
  const consulta = "X-Amz-Algorithm=AWS4-HMAC-SHA256" + `&X-Amz-Credential=${encodeURIComponent(`${credenciales.accessKeyId}/${alcance}`)}` + `&X-Amz-Date=${amzDate}` + "&X-Amz-SignedHeaders=host";
  const solicitudCanonica = ["GET", "/mqtt", consulta, `host:${host}\n`, "host", await sha256Hex("")].join("\n");
  const textoAFirmar = ["AWS4-HMAC-SHA256", amzDate, alcance, await sha256Hex(solicitudCanonica)].join("\n");
  const firma = aHex(await hmac(await claveDeFirma(credenciales.secretKey, dateStamp, region, servicio), textoAFirmar));
  let url = `wss://${host}/mqtt?${consulta}&X-Amz-Signature=${firma}`;
  if (credenciales.sessionToken) url += `&X-Amz-Security-Token=${encodeURIComponent(credenciales.sessionToken)}`;
  return url;
}
```

```javascript
import mqtt from "https://unpkg.com/mqtt@5.16.1/dist/mqtt.esm.js";
import { credencialesInvitado } from "./cognito.js";
import { urlFirmada } from "./sigv4.js";

const ESPERA_RECONEXION_MS = 3000;

// Conecta el navegador a AWS IoT Core por MQTT sobre WebSockets.
// Si la conexión se cae, pide credenciales nuevas a Cognito y vuelve a conectar.
export function crearConexion(config, { suscripciones, alConectar, alMensaje, alCambiarEstado }) {
  let cliente = null;

  function reintentar() {
    setTimeout(abrir, ESPERA_RECONEXION_MS);
  }

  async function abrir() {
    alCambiarEstado("conectando…");
    try {
      const credenciales = await credencialesInvitado(config.region, config.identityPoolId);
      const url = await urlFirmada({ host: config.endpoint, region: config.region, credenciales });
      const nuevo = mqtt.connect(url, {
        clientId: `web-${crypto.randomUUID()}`,
        protocolVersion: 4,
        clean: true,
        reconnectPeriod: 0,
        connectTimeout: 10_000,
      });
      cliente = nuevo;
      nuevo.on("connect", () => {
        nuevo.subscribe(suscripciones, { qos: 1 }, (error) => {
          if (error) {
            alCambiarEstado(`error al suscribirse: ${error.message}`);
            nuevo.end(true);
            return;
          }
          alCambiarEstado("conectado");
          alConectar();
        });
      });
      nuevo.on("message", (topico, payload) => alMensaje(topico, payload.toString()));
      nuevo.on("error", (error) => console.error("MQTT:", error));
      nuevo.on("close", () => {
        if (cliente !== nuevo) return;
        cliente = null;
        nuevo.end(true);
        alCambiarEstado("desconectado, reintentando…");
        reintentar();
      });
    } catch (error) {
      alCambiarEstado(`error: ${error.message}`);
      reintentar();
    }
  }

  abrir();
  return {
    publicar(topico, texto) {
      if (cliente?.connected) cliente.publish(topico, texto, { qos: 1 });
    },
  };
}
```

- [ ] **Paso 3: crear `web/js/app.js`**

```javascript
import { CONFIG } from "../config.js";
import { leerDocumentos, leerGetAceptado, payloadDeseado, topicos } from "./estado.js";
import { crearConexion } from "./iot.js";

const ESPERA_CONFIRMACION_MS = 5000;
const t = topicos(CONFIG.thingName, CONFIG.topicoDisponible);
const $ = (id) => document.getElementById(id);
const controles = [$("encendido"), $("color"), $("brillo")];

let reportado = null;
let temporizador = null;

function habilitar(activo) {
  for (const control of controles) control.disabled = !activo;
}

function pintarFoco() {
  if (!reportado) return;
  const { encendido, color, brillo } = reportado;
  const foco = $("foco");
  foco.style.backgroundColor = encendido ? color : "";
  foco.style.opacity = encendido ? String(0.4 + (0.6 * brillo) / 100) : "";
  foco.style.boxShadow = encendido ? `0 0 ${brillo}px ${brillo / 3}px ${color}` : "";
  $("encendido").textContent = encendido ? "Apagar" : "Encender";
  $("color").value = color;
  $("brillo").value = String(brillo);
  $("brillo-valor").value = String(brillo);
}

function mostrarResumen({ reportado: nuevo, pendiente }) {
  if (nuevo) reportado = nuevo;
  pintarFoco();
  if (pendiente) {
    $("estado-foco").textContent = "esperando confirmación…";
    return;
  }
  clearTimeout(temporizador);
  $("mensaje").textContent = "";
  $("estado-foco").textContent = reportado ? "confirmado" : "sin datos";
}

function enviar(cambios) {
  conexion.publicar(t.update, payloadDeseado(cambios));
  $("estado-foco").textContent = "esperando confirmación…";
  clearTimeout(temporizador);
  temporizador = setTimeout(() => {
    $("mensaje").textContent =
      "El foco no confirmó el cambio. Revisa que la Raspberry Pi y el foco estén encendidos.";
  }, ESPERA_CONFIRMACION_MS);
}

const conexion = crearConexion(CONFIG, {
  suscripciones: [t.documentos, t.rechazado, t.getAceptado, t.disponible],
  alConectar() {
    habilitar(true);
    conexion.publicar(t.get, "");
  },
  alCambiarEstado(texto) {
    $("estado-conexion").textContent = texto;
    if (texto !== "conectado") habilitar(false);
  },
  alMensaje(topico, texto) {
    if (topico === t.documentos) {
      mostrarResumen(leerDocumentos(texto));
    } else if (topico === t.getAceptado) {
      mostrarResumen(leerGetAceptado(texto));
    } else if (topico === t.disponible) {
      $("estado-gateway").textContent = texto === "online" ? "en línea" : "fuera de línea";
    } else if (topico === t.rechazado) {
      $("mensaje").textContent = `AWS rechazó el cambio: ${JSON.parse(texto).message}`;
    }
  },
});

habilitar(false);
$("encendido").addEventListener("click", () => enviar({ encendido: !reportado?.encendido }));
$("color").addEventListener("change", (evento) => enviar({ color: evento.target.value }));
$("brillo").addEventListener("input", (evento) => {
  $("brillo-valor").value = evento.target.value;
});
$("brillo").addEventListener("change", (evento) => enviar({ brillo: Number(evento.target.value) }));
```

## Problemas conocidos

| Síntoma | Causa probable | Solución |
|---|---|---|
| La página: `Cognito GetCredentialsForIdentity: NotAuthorizedException` | El rol de invitado no está asociado al grupo | `terraform -chdir=infra apply` y revisar `aws_cognito_identity_pool_roles_attachment` |
| La página se conecta y se desconecta en bucle | La política del rol no permite `iot:Connect` o un `iot:Subscribe` | Revisar `infra/cognito.tf`. El `clientId` de la página debe empezar con `web-`. |
| Lo mismo, con las políticas correctas | En el flujo mejorado (*enhanced flow*), Cognito limita los servicios que un invitado puede usar | Como prueba, cambiar `allow_classic_flow = true` en `infra/cognito.tf` |
| El puente: `AWS_ERROR_MQTT_UNEXPECTED_HANGUP` | La política del puente no coincide con el ID de cliente o los temas | Revisar `infra/iot.tf` |
| El puente en la Pi: error de TLS al conectar | El reloj de la Pi está mal (no tiene reloj propio y aún no sincronizó la hora) | `timedatectl` debe decir `System clock synchronized: yes`. El servicio se reinicia solo cada 5 segundos hasta que funcione. |
| `FocoNoEncontrado` | El foco está en otra red, en 5 GHz o sin comunicación local | Ver la tarea 19, paso 4 |
| La página se queda en "esperando confirmación…" con el foco encendido | El color reportado no coincide con el pedido | Revisar en el registro del puente qué valores se reportan |
